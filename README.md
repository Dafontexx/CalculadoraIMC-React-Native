# 📱 Calculadora de IMC — React Native

Uma aplicação mobile simples, elegante e funcional para calcular o Índice de Massa Corporal (IMC). Desenvolvida com **React Native** e **Expo**, com interface moderna, ícones e feedback visual intuitivo.

---

## ✨ Funcionalidades

- ✅ Cálculo automático do IMC a partir de peso e altura
- ✅ Aceita altura em metros ou centímetros
- ✅ Classificação conforme critérios da OMS com cores dinâmicas
- ✅ Validação de entrada de dados com alertas amigáveis
- ✅ Tabela de referência embutida
- ✅ Interface responsiva e com ícones
- ✅ Botões para calcular e limpar os dados

---

## 🛠️ Tecnologias Utilizadas

- **React Native** — Framework para desenvolvimento mobile
- **Expo** — Plataforma para executar e testar apps React Native
- **React Native Paper** — Componentes com design Material
- **Expo Vector Icons** — Conjunto de ícones

---

## 🚀 Como executar

```
# Clone o repositório
git clone https://github.com/Dafontexx/CalculadoraIMC-React-Native.git

# Acesse a pasta
cd CalculadoraIMC-React-Native

# Instale as dependências
npx expo install @expo/vector-icons react-native-paper react-native-safe-area-context

# Inicie o projeto
npx expo start
```

Escaneie o QR Code com o app **Expo Go** no seu celular e pronto! 🎉

## 📊 Classificação do IMC

Tabela

| IMC | Classificação | Cor |
| --- | --- | --- |
| < 18,5 | Abaixo do peso | 🟡 Amarelo |
| 18,5 – 24,9 | Peso normal | 🟢 Verde |
| 25,0 – 29,9 | Sobrepeso | 🟡 Amarelo |
| 30,0 – 34,9 | Obesidade Grau I | 🟠 Laranja |
| 35,0 – 39,9 | Obesidade Grau II | 🔴 Vermelho |
| ≥ 40,0 | Obesidade Grau III | 🔴 Vermelho escuro |
